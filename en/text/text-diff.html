About Text Diff

Text diff is a technique for comparing differences between two blocks of text. This tool uses the LCS (Longest Common Subsequence) algorithm for line-level comparison.

  • Green background Added content
  • Red background + strikethrough Deleted content
  • White background Unchanged content

About Text Diff

Text Diff is a completely free online tool that helps you Compare two texts for differences. Whether you are a casual user or a professional, you can use it instantly without installing any software.

It is especially useful for writers, editors, students and web developers who work with text every day and need quick, reliable processing.

How to Use Text Diff

  1. Paste or type your text into the input area.
  2. Configure the options to match your exact requirements.
  3. Click the Process button to get the result immediately.
  4. Use the copy button to save the output to your clipboard.
