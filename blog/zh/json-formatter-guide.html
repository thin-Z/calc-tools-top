JSON格式化工具：美化、压缩和校验JSON数据

JSON（JavaScript Object Notation）是当前最流行的数据交换格式之一。无论是在API开发、配置文件管理、还是数据存储中，JSON都无处不在。

JSON格式化与压缩

格式化（美化）：将压缩的JSON转为带有缩进和换行的可读格式，方便阅读和调试。

压缩：移除所有空格和换行，将JSON压缩为一行，减小数据传输体积。

为什么需要JSON校验

一个语法错误的JSON会导致程序解析失败。常见的JSON错误包括：漏掉逗号、多余的逗号、字符串未加引号、使用单引号（JSON要求双引号）等。

JSON使用小技巧

1. 密钥名称必须用双引号包裹；2. 字符串必须用双引号，不能用单引号；3. 不支持注释（部分扩展格式除外）；4. 最后一个元素后面不能有逗号。

如何使用JSON格式化工具

拿到一段杂乱或报错的数据时，按三步处理：

  • 第一步：粘贴 JSON 文本到输入框。
  • 第二步：点击"格式化"美化缩进，或点"压缩"合并成一行。
  • 第三步：若报错，工具会标出错误位置，按提示修掉多余逗号或引号即可。

常见问题（FAQ）

为什么提示"Unexpected token"？
多半是用了单引号、键名没加引号，或某处多了/少了逗号。定位到报错行附近检查括号和引号配对。
格式化会改我的数据吗？
不会。美化只调整缩进和换行，不改变字段名、值和结构，压缩也只是去掉空白。
大文件能处理吗？
可以，但特别大的文件在浏览器里可能卡顿。超大日志建议先截取关键片段再格式化。
JSON 能写注释吗？
标准 JSON 不支持注释。若需注释可用 JSON5 等扩展格式，但对方解析器必须支持，否则会报错。

小贴士

  • 提交前先校验：调用接口前把请求体格式化检查一遍，能提前发现字段拼错、类型不对等问题。
  • 用折叠看结构：美化后按层级缩进，先从最外层看清对象嵌套，再深入调试，效率更高。
