在线图片裁剪工具

无需上传图片到任何服务器。所有裁剪处理通过 Canvas API 在浏览器本地完成，支持拖拽移动裁剪框、调整大小、比例锁定与实时预览。

适用场景

社交媒体头像、电商主图、公众号封面、证件照裁剪、网页配图等，需要快速得到指定比例或尺寸的图片时都可以使用。

使用提示

先选择比例（如 1:1 或 16:9），再拖拽调整裁剪框位置；在框外拖拽可重新绘制选框。裁剪结果可下载 PNG 或 JPEG 格式。
