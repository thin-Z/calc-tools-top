在线图片裁剪缩放：自由调整图片尺寸

图片裁剪缩放松工具是一款完全免费的在线工具，让你无需安装 Photoshop 等重型软件，就能把图片改成任意尺寸，无论是缩小成网站缩略图、裁剪成社交媒体头像，还是放大到打印所需的分辨率，都能在几秒内完成。所有处理都通过浏览器内置的 Canvas API 在你本地完成，图片不会上传到任何服务器，因此既保护隐私，又无需等待上传下载。

它特别适合需要频繁改图尺寸但不想被价格与安装门槛劝退的普通用户、自媒体运营者，以及想快速预处理素材的前端开发者。

图片缩放到底做了什么？

图片的尺寸由"宽度 × 高度"的像素数决定。缩放的本质，是根据目标尺寸重新绘制每一个像素点：缩小时需要从原图里"挑选"有代表性的像素，放大时则需要"推断"新的像素颜色。Canvas API 会在后台完成这部分计算，并用高质量的插值算法尽量减少缩放带来的画质损失。

需要特别说明的是，放大图片并不会凭空增加细节——它只是把已有的像素拉大、用算法填充中间空隙，所以一张模糊的小图放大后依然可能模糊。真正能保证画质的，是从原图就保留足够的像素信息。

具体怎么用？

1. 把图片拖拽进虚线框，或点击"选择文件"（支持 JPG / PNG / WebP / BMP / GIF，最大 50MB）。
2. 在"宽度"和"高度"输入框里填入目标像素值（通常你只需要填一个，另一个会按比例自动算好）。
3. 勾选"保持宽高比"，这样宽度或高度改变时，另一维度会自动等比例调整，避免图片被拉伸变形。
4. 点击"开始缩放"，右侧立即预览缩放结果与原图对比。
5. 确认满意后，点击"下载缩放图片"保存到本地。

常见误区与注意点

① 别把"保持宽高比"关掉。 如果手动填了不匹配的宽高比且取消了勾选，图片会被整体拉伸或压扁，导致形变。除非你刻意要这种效果，否则保持勾选。
② 放大不等于变清晰。 对图源分辨率不足的图片，放大到超过原尺寸后画质会变模糊，正确做法是尽量使用更高分辨率的原始素材。
③ 用对格式。 缩放后导出为 JPG 适合照片，PNG 适合需要透明背景的设计图，WebP 则能在体积与画质间取得较好平衡。

宽高比与常见尺寸速查

很多场景其实有标准尺寸：社交媒体头像常用 1:1（如 400×400），Banner 常用 16:9（如 1920×1080），打印照片常用 3:2 或 4:3。你可以直接查阅你所在平台的规格，再让工具按比例缩放，效率更高。

缩放结果该怎么用？

调整完成的图片可以直接用于网页配图、文章封面、电商主图、社群头像或打印。如果你还想进一步减小文件体积，可以接着用本站的「图片压缩」工具把缩放后的图片再压一次，让页面加载更快、更省流量。

插值算法怎么选

浏览器 Canvas 在缩放时会用插值算法补出新的像素值。缩小时算法影响不大，放大时差别明显。

常见插值方式对比
方式原理缩小效果放大效果速度
最近邻直接取最近的像素易出现锯齿块状明显最快
双线性取周围四个像素加权平均平滑自然略软快
双三次 / Lanczos取更大邻域做加权细节保留较好边缘更锐利较慢

打印尺寸与响应式断点

常见问题

为什么缩小后体积降得比质量调整更明显？体积大致与像素总量成正比，边长减半意味着像素只剩四分之一，因此先缩尺寸通常最有效。

能把小图放大变清晰吗？不能。插值只能补出新像素的估计值，无法恢复原始细节，放大后画面会变软。

锁定比例有什么作用？避免只改一边导致的拉伸变形；需要特定构图时，应改用裁剪而不是强行拉伸。

网页图片应该输出多大？按显示宽度乘以设备像素比准备，并提供几档尺寸供浏览器选择，比一张超大图更省流量。
