Markdown 是什么？

Markdown 是一种轻量级标记语言，用简单的符号表示排版：`#` 表示标题、`**` 表示粗体、`-` 表示列表、反引号表示行内代码或代码块。Markdown 文件易读易写，是 GitHub、博客平台和技术文档的事实标准。本预览器支持常用语法子集：1-6 级标题、粗体与斜体、行内代码、围栏代码块、有序与无序列表、链接、引用、分隔线和表格，覆盖日常写作与文档排版的绝大多数场景。

常用语法速查

  • 标题：`# 一级标题` 到 `###### 六级标题`
  • 粗体/斜体：`**粗体**`、`*斜体*`
  • 行内代码：`` `代码` ``；代码块：``` ```语言 ```
  • 列表：`- 无序` 或 `1. 有序`
  • 表格：用 `|` 分隔列，第二行为 `|---|---|`

如何使用本工具

  1. 在编辑区输入或粘贴 Markdown 内容
  2. 右侧（下方）实时显示渲染结果，输入停顿 150ms 后刷新
  3. 点击「填入示例」快速体验全部语法，点击「清空」重新开始
  4. 编辑区下方显示当前字数（中文字符与英文单词合计）

常见问题

支持任务列表和图片语法吗？当前版本暂不支持任务列表与图片语法，其余常用语法均已覆盖。如需图片上传，请使用其他工具配合。

渲染结果安全吗？安全。所有内容在渲染前都会进行 HTML 转义，脚本标签与危险链接会被过滤，不会执行任何代码。

内容会保存或上传吗？不会。编辑与预览全部在浏览器本地完成，刷新页面后内容即清除。
