URL编解码工具：什么是URL编码？为什么要编码？

URL编码（又称百分号编码）是Web开发中的基础概念。它确保URL中的特殊字符能被正确传输和解析。

什么是URL编码？

URL中只允许使用ASCII字符集中的字母、数字和部分特殊符号。其他字符（如中文、空格、&等）需要编码为%后跟两位十六进制数的格式。

例如：空格编码为%20，中文'你好'编码为%E4%BD%A0%E5%A5%BD

什么时候需要URL编解码

GET请求参数：URL中的查询参数包含特殊字符时需要进行编码。

URL路径：路径中包含中文或特殊字符的文件名。

表单提交：application/x-www-form-urlencoded格式提交的数据会自动编码。

常见需要编码的字符

空格 → %20、& → %26、? → %3F、= → %3D、# → %23、中文 → 多字节编码

如何使用URL编解码工具

调试接口或处理链接时，按三步完成转换：

  • 第一步：粘贴需要处理的网址或参数文本。
  • 第二步：选择"编码"或"解码"方向。
  • 第三步：复制结果，直接用于请求或填入地址栏。

常见问题（FAQ）

编码和解码是一一对应的吗？
是的。只要用同一套标准百分号编码规则，先编码再解码就能还原原值。
为什么中文地址复制后变乱码？
含中文的 URL 若未编码就会出问题。把中文部分编码为 %XX 形式，浏览器和服务端才能正确解析。
+ 号在解码后变成空格？
在 form-urlencoded 规范里 + 代表空格，但严格 URL 编码中空格是 %20。两者混用会错位，建议统一用 %20。
前端该用哪个函数？
JavaScript 编码参数用 encodeURIComponent，整段网址用 encodeURI；解码对应 decodeURIComponent 与 decodeURI。

小贴士

  • 只对参数值编码：不要把整个 URL 连同 ?、&、= 一起编码，否则分隔符失效，应只编码每个值。
  • 服务端也要解码：前端编码后，后端需用对应函数解码，前后规则一致才能拿到正确参数。
