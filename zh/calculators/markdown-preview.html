Markdown 是什么？

Markdown 是一种轻量级标记语言，用简单的符号表示排版：`#` 表示标题、`**` 表示粗体、`-` 表示列表、反引号表示行内代码或代码块。Markdown 文件易读易写，是 GitHub、博客平台和技术文档的事实标准。本预览器支持常用语法子集：1-6 级标题、粗体与斜体、行内代码、围栏代码块、有序与无序列表、链接、引用、分隔线和表格，覆盖日常写作与文档排版的绝大多数场景。

常用语法速查

  • 标题：`# 一级标题` 到 `###### 六级标题`
  • 粗体/斜体：`**粗体**`、`*斜体*`
  • 行内代码：`` `代码` ``；代码块：``` ```语言 ```
  • 列表：`- 无序` 或 `1. 有序`
  • 表格：用 `|` 分隔列，第二行为 `|---|---|`

为什么要用 Markdown 写东西？

Markdown 最大的好处，是让你在"不打断思路"的情况下完成排版。相比用 Word 反复点菜单调格式，你只需要敲几个简单的符号（比如 `#` 代表标题、`**` 代表加粗），就能得到结构清晰、格式统一的文档。写完的源文件是纯文本，任何编辑器都能打开，也不会因为软件版本不同而出现排版错乱——这正是它被 GitHub、博客、技术文档广泛采用的原因。

对写作者来说，Markdown 让你把注意力集中在"内容"而非"格式"上；对开发者来说，它能轻松转成 HTML、PDF、网页等格式，方便发布与分享。学会常见的几个语法，几乎可以覆盖日常写作和文档排版的 90% 需求，性价比非常高。

容易出错的语法细节

① 空格与断行。 某些 Markdown 渲染器对"标题后要不要空格"、空行是否影响段落分割有严格规定，写得不符合规范时，预览结果可能和预期不符。写完后最好预览确认一下。

② 嵌套列表。 有序列和无序列、以及多层级列表的缩进，不同的 Markdown 方言处理方式不同，嵌套过深容易变得混乱。

③ 特殊字符转义。 像反引号、星号这类 Markdown 保留符号，如果要当普通文本显示，需要加反斜杠转义，否则会被当成语法处理。

结果怎么用？

通过实时预览，你能立刻看到写好的 Markdown 渲染出来的样子：标题的层级、加粗斜体、列表缩进、代码高亮、表格对齐是否正确，一目了然。它非常适合写 README、博客草稿、技术文档、笔记，以及需要"所见即所得"效果的写作场景。改到满意后，把源 Markdown 复制到你的平台或工具即可发布，预览只是帮你确认最终效果。
