分数计算器

在线分数计算器，支持真分数与假分数的加、减、乘、除四则运算，输入分子与分母即可实时计算，结果自动约分为最简分数，除以 0 与非法分数会给出提示。

什么是分数计算器？

分数计算器用于对两个分数执行加、减、乘、除运算。分数由分子（在上）与分母（在下）构成，分母不能为 0。本工具把所有运算结果自动约分为最简分数（分母为 1 时显示为整数），全程在浏览器本地完成，输入不会上传到服务器。

如何使用本工具

  1. 在「第一个分数」的分子与分母输入框中填写数字（分母不能为 0，分子可为负数）
  2. 选择要执行的运算：加（＋）、减（−）、乘（×）或除（÷）
  3. 在「第二个分数」的分子与分母输入框中填写数字
  4. 结果区会实时显示「第一个分数 运算符 第二个分数 = 结果」的完整算式

常见问题

结果为什么会自动约分？例如 2/4 与 1/2 表示同一个数，本工具会把它约分成最简分数 1/2，方便直接阅读与使用。

分母可以为 0 吗？不可以。任何数的分母为 0 都没有意义，工具会提示「分母不能为 0」。

做除法时第二个分数的分子为 0 怎么办？这等价于除以 0，结果无意义，工具会显示「除数不能为 0」的提示。

数据会上传到服务器吗？不会。所有计算都在浏览器本地完成，输入的数据不会离开你的设备。
